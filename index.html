A private Minecraft: Java Edition launcher

MyLauncher is a Windows desktop launcher designed for a small private group of users. It manages Minecraft runtimes, mod loaders, modpack files, updates and Microsoft account sign-in in one application.

Supported runtimes

Vanilla Minecraft, NeoForge, Fabric and Forge.

Managed installation

Separate instances, integrity checks, repair and controlled updates.

Microsoft sign-in

System-browser authentication using Microsoft's official identity platform.

About MyLauncher

MyLauncher is an independently developed launcher intended to simplify installation and maintenance of a small set of private Minecraft modpacks.

The launcher uses official Minecraft metadata and services where applicable and keeps game instances separate from the user's standard .minecraft directory.

Current status

Microsoft OAuth, Xbox User Authentication and XSTS authorization are implemented. Access to Minecraft Services is pending approval of the MyLauncher Application ID.
